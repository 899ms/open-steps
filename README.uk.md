## Навіщо це

Я не інженер. Двадцять років я роблю продукти з боку продукту, сьогодні в моїй компанії понад 50 розробників. Паралельно я почав робити продукт сам, з агентом і без інженерів. Майже одразу наштовхнувся на стіну. Агент добре працює, а потім розповідає про зроблене хешами комітів і жаргоном, і я не можу зрозуміти, закінчили ми чи ні. Сама робота при цьому зроблена нормально. Просто агента ніхто не вчив говорити з людиною, яка не читає код.

Цей пак учить. Він не пише код замість агента і не перевіряє код за нього. Він змінює те, що агент каже вам у кількох важливих моментах, і вимагає доказів там, де раніше вистачало слова «готово».

## Що роблять навички

| Навичка | Що робить | Коли спрацьовує |
|---|---|---|
| `os-done-or-not` | Звіт на один екран із вердиктом: зроблено чи ні, що потрібно від вас, чи з'явилися нові борги, чи можна закривати. У кожного «так» є доказ | Робота закінчена, або ви питаєте, як усе пройшло |
| `os-step-by-step` | Покрокова інструкція без жаргону, яку може виконати людина без технічної підготовки. Спочатку агент має спробувати все сам і попросити лише те, що справді потрібно від вас | Агенту треба, щоб ви щось запустили, вставили, натиснули, схвалили чи перевірили |
| `os-ask-simple` | Питання простими словами, у що воно обійдеться потім, і одна позначена рекомендація | В агента до вас питання або варіанти |
| `os-what-could-go-wrong` | Вважає, що рішення вже провалилося, і шукає чому. Це робить окремий свіжий агент, який до рішення не причетний. Наприкінці один вердикт | Ось-ось ухвалять рішення, яке важко скасувати: договір, покупка, міграція, запуск |
| `os-whats-next` | Спочатку закриває те, що вже перевірено й готове, потім радить наступне завдання і пояснює чому простими словами | Ви питаєте, що лишилося або що робити далі |
| `os-check-work` | Не вірить звіту іншої сесії на слово. Звіряє кожне твердження з тим, що сталося насправді, і каже, що з цим робити | Інша сесія каже, що закінчила |
| `os-say-simple` | Переказує будь-який текст простими словами, не втрачаючи фактів і поганих новин. Назвіть число і отримаєте рівно стільки пунктів | Будь-який текст читається як інженерний: звіт, коментар, помилка, відповідь самого агента |
| `os-big-picture` | Веде один файл `BIG-PICTURE.md`: що це за продукт, кожна функція і як далеко вона дійшла, що давно ніхто не чіпав, що в черзі. Якщо у вас уже є трекер задач, пропонує відкрити чергу як задачі в ньому | Ви питаєте, де ми зараз, або щойно записано звіт сесії |

Агент відповідає тією мовою, якою ви з ним говорите. Код, назви файлів і команди лишаються англійськими.

## Встановлення

Пак зроблено і виміряно на Claude Code, там усе працює без додаткових кроків. Навички також ставляться в Codex, Cursor і Gemini CLI, див. [інші агенти](docs/other-agents.md) (англійською).

Скачайте репозиторій:

```bash
git clone https://github.com/kharmanskyi/open-steps.git
```

Обидві команди нижче запускаються з папки, куди ви його скачали, тієї, де тепер лежить `open-steps/`, а не зсередини. Встановіть як плагін:

```bash
claude plugin marketplace add ./open-steps && claude plugin install open-steps@open-steps
```

Готово: навички й обидва хуки підключено. Подивитися, що вийшло:

```bash
claude plugin details open-steps
```

Одну річ варто додати руками, установник цього не зробить: короткий блок у ваш `~/.claude/CLAUDE.md`. Навички агент обирає сам. Хуки йому нагадують, а цей блок перетворює нагадування на правило, яке переживає довгі розмови. Одна команда з тієї ж папки, її безпечно повторювати:

```bash
grep -q 'os-done-or-not' ~/.claude/CLAUDE.md 2>/dev/null || cat open-steps/docs/routing-block.md >> ~/.claude/CLAUDE.md
```

Пізніше перевірити все встановлення, а не лише плагін: команда `/open-steps:os-install-check` всередині агента. Вона каже, що підключено, що ні, і пише «не перевірено» там, де не змогла подивитися.

## Оновлення і видалення

Оновити: `git pull` всередині `open-steps/`, потім `claude plugin update open-steps@open-steps`. Потрібні обидві половини: плагін оновлюється з вашої папки, а не з GitHub, і файли потрапляють у встановлену копію лише коли змінився номер версії. Видалити: `claude plugin uninstall open-steps`, потім прибрати блок із `CLAUDE.md`.
